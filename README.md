

Pasos para ejecutar y usar esta herramienta:

1. Clonar o descargar: Copia el archivo `DDoSIp.py` y ábrelo en tu editor de código o terminal. Este script utiliza módulos nativos de Python (`random`, `socket`, `os`), por lo que no requiere dependencias externas adicionales.

2. Lanzar el script: Ejecuta el archivo desde tu consola con el comando:
```
python DDoSIp.py
```
